# Yash Sunil More - Resume Website

This is a professional resume website showcasing my education, projects, achievements, and technical skills.

## Setup Instructions

### Adding Images

The website requires the following images:

1. **Profile Picture** (`images/profile.jpeg`) - Already exists
   - Your main profile photo that appears at the top of the page
   - Recommended size: 200x200 pixels (circular crop will be applied)

2. **IIIT Hyderabad Image** (`images/iiith-placeholder.jpg`)
   - Replace the placeholder with an image of IIIT Hyderabad
   - Recommended size: 300x200 pixels

3. **RIMC Dehradun Image** (`images/rimc-placeholder.jpg`)
   - Replace the placeholder with an image of RIMC Dehradun
   - Recommended size: 300x200 pixels

### How to Replace Placeholder Images

Simply replace the placeholder files with your actual images:
- Keep the same filenames
- Supported formats: JPG, JPEG, PNG
- The website will automatically display your images

## Features

- Clean, professional design based on your resume
- All hyperlinks from your resume are included
- Responsive design that works on mobile and desktop
- Easy to update and maintain

## Sections Included

1. **Profile** - Name, contact info, GitHub, LinkedIn
2. **Education** - IIIT Hyderabad and RIMC with detailed coursework
3. **Projects** - Three major projects with GitHub links
4. **Position of Responsibility** - E-Cell experience
5. **Achievements** - JEE ranks and RIMC selection
6. **Technical Skills** - All your programming languages and tools

## Execution Instructions

1. Ensure you have a web browser installed on your system.
2. Open the `index.html` file in the browser to view the website.
   - You can do this by double-clicking the file or right-clicking and selecting "Open with" followed by your preferred browser.
3. To make changes to the website:
   - Edit the `index.html` file for content updates.
   - Modify the `styles.css` file for styling changes.
   - Update the `script.js` file for JavaScript functionality.
